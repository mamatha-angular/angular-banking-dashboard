# Angular Banking Dashboard

A responsive banking dashboard application developed using Angular 20.

## Technologies
- Angular 20
- TypeScript
- Javascript
- RxJS
- Angular Material
- HTML5
- CSS3
- REST API
- C#
- Sql

## Features
- User authentication
- Account management
- Transaction management
- Loan management
- Employee management
- Search, filter and sorting
- Reactive form validation
- Role-based access
- Responsive UI

## How to Run

npm install
ng serve
